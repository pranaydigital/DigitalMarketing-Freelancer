# PRANAY.DIGITAL — Spider Portfolio

A multi-page cinematic Spider-Man-inspired portfolio for a digital marketing freelancer.

## Pages
- `index.html` — Home / cinematic hero
- `services.html` — Services / superpowers
- `projects.html` — Projects + screenshot proof
- `about.html` — About Pranay
- `contact.html` — Contact

## Interaction
- Hover the Spider-Man mask in the hero: it reveals Pranay's real portrait.
- A web-crawler moves down the right side while the page scrolls.
- A left-side Spider-Man greeting appears during scrolling.
- A subtle web-trail follows the mouse cursor.
- Persistent low-opacity spider-web geometry and scrolling banners are used across the site.

## Visual note
The hero character uses an original MCU-style red/blue Spider-Man suit treatment rather than a photorealistic likeness of the actor. This keeps the portfolio visual original while retaining the requested suit aesthetic.

## Deploy to GitHub Pages
Upload the **contents** of this folder to the repository root, not the folder itself. Set Pages to `main / (root)`.

Replace the placeholder WhatsApp number and email in `contact.html` / the header links before publishing.
